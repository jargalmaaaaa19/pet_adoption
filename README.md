# Тэжээвэр амьтан үрчлүүлэх болон төөрч олдсон амьтдыг эзэнд нь холбох систем

## Төслийн тухай
Энэхүү төсөл нь "Программ хангамж хөгжүүлэлтийн процесс" хичээлийн лабораторийн ажлын хүрээнд хэрэгжүүлж буй бие даасан веб аппликейшн юм. Манай систем нь гэрийн тэжээвэр амьтан үрчлүүлэх үйл явцыг хялбарчлах, мөн гудамжинд төөрч үрэгдсэн эсвэл олдсон амьтдыг эзэнтэй нь түргэн шуурхай холбох зорилготой юм.

## Багийн гишүүд ба үүрэг хуваарилалт
Энэхүү төслийг Scrum аргачлалын дагуу багийн гишүүд хамтран хөгжүүлж байна:
- Д.Дэлгэрмаа – Product Owner (PO): Бүтээгдэхүүний шаардлагыг тодорхойлж, хэрэгцээг чиглүүлэх
- О.Доржсамбуу – Scrum Master (SM): Scrum процессыг зохион байгуулж, тулгарсан саад бэрхшээлийг шийдвэрлэх
- Б.Энхбаяр– Development Team (Хөгжүүлэгч): Код бичих, систем хөгжүүлэх болон турших
- З.Жаргалмаа – Development Team (Хөгжүүлэгч): Код бичих, систем хөгжүүлэх болон турших

## Төслийн үндсэн зорилго
1. **Scrum аргачлалыг эзэмших:** Багаар ажиллах чадварыг хөгжүүлж, бүтээгдэхүүний Backlog болон User Story-той ажиллаж сурах.
2. **Амьтан үрчлүүлэх үйлчилгээ:** Шинэ эзэн хайж буй амьтдын мэдээллийг байршуулж, үрчлэн авах хүсэлтэй хүмүүстэй холбож өгөх.
3. **Төөрсөн амьтдыг эзэнд нь олох:** Алга болсон болон олдсон амьтдын зар мэдээллийг түргэн шуурхай түгээж, эзнийг нь олоход туслах.

# Pet Adoption Project - Lab 4: Sprint Planning & Unit Testing

## 1. Project Overview (Төслийн тухай)
Энэхүү төсөл нь гэрийн тэжээвэр амьтан үрчлүүлэх үйл явцыг цахимжуулах, хэрэглэгчид болон амьтан хамгаалах байгууллагуудыг холбох систем юм. Лабораторийн ажлын хүрээнд Agile Scrum аргачлал, GitHub Projects ашиглан Backlog удирдлага болон TDD (Test-Driven Development) аргаар нэгжийн тест бичиж хөгжүүлж байна.

## 2. Definition of Done (DoD) - Ажил дууссан гэж үзэх шалгуур
Манай багийн хөгжүүлэлтийн ажлыг "Done" гэж үзэх дараах стандартыг мөрдөнө:
- **Код бичигдсэн:** Функциональ болон логикийн шаардлага хангасан код бичигдсэн байх.
- **Нэгжийн тест (Unit Test):** Код нэгжийн тестлэлд (Jest) 100% амжилттай давсан байх.
- **Code Review:** Багийн өөр гишүүнээр код шалгуулж, хянуулсан байх.
- **Coding Standards:** Багийн тогтоосон код бичих дүрэм, стандартыг баримталсан байх.
- **Test Cases:** Бүх зорилтот тест кэйсүүд алдаагүй ажилласан байх.
- **Documentation:** Шаардлагатай функц болон зааврын тайлбар бичигдсэн байх.

## 3. Lab 4 Implementation (Лабораторийн ажлын хэрэгжилт)
